# Память по проекту Good Karma

## Откуда взялся проект

Сначала был прототип: один самодостаточный `index.html` (~600 КБ) на vanilla JS
с данными в `<script id="gk-seed">`. Прошёл через десяток итераций дизайна —
от функционального билда до editorial-типографики. Потом решили делать
настоящий сайт и переехали на Next.js. Прототип остался как источник
визуальных решений: вся палитра, композиции секций и тексты перенесены из него.

## Ключевые решения, которые обсуждались и приняты

**Скидка за самовывоз отменена.** Была −10%, владелец решил убрать полностью:
из формулы, текстов, акций, админки. Самовывоз остался способом получения.

**Трекинг без обратного отсчёта.** Убрали ETA и персонажа-курьера — доставку
будет вести сторонняя площадка. Остались статусы и кнопка «Узнать о заказе».

**Маскотов-иконок в интерфейсе быть не должно.** Владельцу не понравились
линейные SVG-звери в основной части сайта. Функциональные иконки (корзина,
поиск, стрелки) — нужны. Маскоты — только как крупные иллюстрации в
Karma Club и пустых состояниях.

**Конструктор пиццы как отдельная фича — отменён.** Вместо него добавки
выбираются прямо в карточке блюда. Конструктор вока — остаётся, это
signature-фича.

**Montserrat — основной шрифт всего сайта**, Cormorant Garamond только для
крупных editorial-заголовков (примерно 20% текста).

**База данных.** Пробовали Docker — не установлен. Перешли на Supabase
(Ирландия). Мучились с подключением: порт 6543 (пулер) виснет намертво,
работает только 5432. Пароль не должен содержать `?`, `/`, `@`, `#`.

## Найденные и исправленные баги (не повторять)

- **Цвета в CSS-переменных как hex ломают прозрачность в Tailwind.** Классы
  вида `border-plum/30` молча исчезали из собранного CSS. Лечится хранением
  токенов как RGB-троек и обёрткой `rgb(var(--x) / <alpha-value>)`.
- **Декоративная обёртка ломала раскладку акций.** Классы `grid-cols-2`
  передавались во внешний контейнер, а контент заворачивался в лишний div —
  колонки схлопывались, фото падало под текст.
- **`tint-lavender` использовался, но не был объявлен** в конфиге Tailwind.
- **Секции без `position: relative`** — цветные размытые пятна позиционировались
  относительно всего документа и заливали страницу.
- **Сид был неидемпотентным** — повторный запуск дублировал записи.

## Как владелец даёт задачи

Присылает подробные ТЗ на несколько экранов с нумерованными разделами,
скриншоты с обведёнными проблемными местами и визуальные референсы.
Просит не переспрашивать и сразу вносить изменения. Ценит, когда находишь
настоящую причину проблемы, а не подгоняешь внешний вид.

Язык общения — русский.

## Договорённости по процессу

- Проверять работу реальным прогоном, а не «на глаз»: собирать CSS и
  проверять, что классы попали в сборку; прогонять граничные значения
  в логике денег (`npm run check:delivery`).
- Отличать реальные ошибки TypeScript от известного Prisma-каскада
  (см. CLAUDE.md).
- Честно говорить про ограничения: качество присланных ассетов, невозможность
  сгенерировать растровые иллюстрации, требования 152-ФЗ.
